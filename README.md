# C# Projects

These are console applications and exercises covering C# fundamental to advanced concepts.

## What's Included

- **AppInterfaces**: Using interfaces to share actions across different classes (like PasswordManager and TodoList)

- **ArchitectArithmetic**: Calculating shapes, floor areas, and tile costs for famous buildings

- **CaesarCipher**: Encrypting and decrypting secret text messages by shifting letters

- **CorporatePolymorphism**: Sharing and customizing work methods across different job roles (Manager, Engineer, HR, Intern)

- **CyberLibraryManagement**: Adding, searching, and managing books using lists

- **EscapeRoomAdventure**: Text-based puzzle game with agent codes and system status checks

- **ExpenseTracking**: Managing company expense types and approval stages

- **LibraryManagementSystem**: Managing book checkouts and preventing duplicate book IDs

- **OOYA**: Creating user dating profiles with hobbies and bio details

- **RoverControlCenter**: Controlling space rovers and satellites with shared commands

- **SmartAutomationSystem**: Automating smart home devices like lights and alarms when sensors trigger

## How to Run

Requirements: [.NET SDK 8.0+](https://dotnet.microsoft.com/download)

```bash
cd <ProjectDirectory>
dotnet run
```

Example:
```bash
cd LibraryManagementSystem
dotnet run
```
