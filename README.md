# C# Projects

These are console applications and exercises covering C# fundamental to advanced concepts.

## What's Included

- **AppInterfaces**: Using interfaces to share actions across different classes (like PasswordManager and TodoList)

- **ArchitectArithmetic**: Calculating shapes, floor areas, and tile costs for famous buildings

- **BiblicalInheritance**: Parent and child classes for managing books, magazines, and videos

- **CaesarCipher**: Encrypting and decrypting secret text messages by shifting letters

- **Classes**: Creating classes, fields, properties, and constructors

- **CodewarsSolution**: Solving coding challenges and logic puzzles

- **CorporatePolymorphism**: Sharing and customizing work methods across different job roles (Manager, Engineer, HR, Intern)

- **CyberLibraryManagement**: Adding, searching, and managing books using lists

- **Encapsulation**: Protecting class data with private fields and property rules

- **Enums**: Working with fixed lists of named choices (like days of the week or colors)

- **EscapeRoomAdventure**: Text-based puzzle game with agent codes and system status checks

- **ExpenseTracking**: Managing company expense types and approval stages

- **GenericType**: Using generic code that works safely with different data types

- **Generics**: Reusable generic classes and methods that handle empty (null) values safely

- **InventoryManagement**: Tracking store products and stock quantities using dictionaries

- **LibraryManagementSystem**: Managing book checkouts and preventing duplicate book IDs

- **OOYA**: Creating user dating profiles with hobbies and bio details

- **PasswordChecker**: Checking password strength and giving a security score from 1 to 5

- **PhotoFilter**: Applying filters (like brightness and contrast) to images using delegates

- **ProgrammingLanguages**: Searching and filtering programming language data using LINQ

- **RoverControlCenter**: Controlling space rovers and satellites with shared commands

- **SmartAutomationSystem**: Automating smart home devices like lights and alarms when sensors trigger

- **SmartTemperatureSensor**: Reading and converting temperatures (Celsius, Fahrenheit, Kelvin) using structs

- **SortedDict**: Comparing sorted dictionary performance with standard dictionaries

- **StellarLifecycleSimulator**: Simulating how stars grow, burn, and change over time

- **TrueOrFalse**: Simple true or false console quiz game with score tracking

## How to Run

Requirements: [.NET SDK 8.0+](https://dotnet.microsoft.com/download)

```bash
cd <ProjectDirectory>
dotnet run
```

Example:
```bash
cd LibraryManagementSystem
dotnet run
```
